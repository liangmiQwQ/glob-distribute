# glob-distribute

Convert glob AND expressions into OR alternatives.

## Status

Project scaffold only. Glob conversion and the public API are not implemented yet.
The package is not published to npm.

## Development

```sh
pnpm install
pnpm check
pnpm build
pnpm test
```

Requires the Node.js version in `.node-version`. Tests currently allow an empty suite.
See [CONTRIBUTING.md](./CONTRIBUTING.md) for release setup.
